# Problem: Recursive Merge Sort (PA#3 Custom Problem)

Implement the Merge Sort algorithm in C++ to sort an array of integers in non-decreasing order.

## Constraints
- **C1 (Ban-list)**: Do not use `std::sort` or `std::stable_sort` from `<algorithm>`.
- **C2 (Semantic)**: The solution must implement the Merge Sort algorithm using recursion (`mergeSort(a, left, right)`), dividing the range in half and merging sorted halves.
